## Application Mindmap (Pages & Modules)

Based on your Marks Management, Students, Financials, and Finova templates — scoped to **Marks & Performance** with two roles:

```mermaid
flowchart TB
    subgraph Auth["Authentication"]
        Login["Login Page"]
        SignUp["Sign Up Page"]
    end

    subgraph Shell["App Shell (Post-Login)"]
        Header["Header: Search · Term · Notifications · Profile"]
        Sidebar["Dark Sidebar Navigation"]
        Footer["Status Bar: DB · Backup · Sync · Storage · Health"]
        WhiteArea["White Workspace (Cards, Charts, Tables)"]
    end

    subgraph Performance["Marks & Performance Module"]
        PDash["Dashboard ✓"]
        Assess["Assessments"]
        Marks["Marks Entry"]
        Grade["Gradebook"]
        Perf["Student Performance"]

        Mod["Moderation (Admin only)"]
        Reports["Report Cards"]
        AI["AI Insights"]
        Settings["Settings"]
    end

    subgraph Roles["Role Access"]
        Admin["Administrator — Full access"]
        Entrant["Data Entrant — Entry + limited views"]
    end

    Login --> Shell
    SignUp --> Shell
    Sidebar --> Performance
    Admin --> Mod
    Admin --> Analytics
    Entrant --> Marks
    Entrant --> Assess
```

## MVVM Architecture

| Layer | Responsibility | Key Files |
|-------|----------------|-----------|
| **Models** | Domain data | `User`, `UserRole`, `KpiMetric`, `NavMenuItem` |
| **ViewModels** | UI state, commands | `LoginViewModel`, `SignUpViewModel`, `DashboardViewModel` |
| **Views** | XAML only (white workspace focus) | `LoginView`, `SignUpView`, `DashboardView` |
| **Services** | Auth, session, navigation | `AuthService`, `SessionService`, `NavigationService` |
| **Controls** | Reusable UI | `AuthIllustration`, `KpiCard`, `StatusFooterBar`, `WhitePanel` |
| **Resources** | Design tokens | `Resources/DesignTokens.xaml` |

---

## UI Design Mapping (From Your Mockups)

| Mockup | Applied To |
|--------|------------|
| **Finova login split** | Login/SignUp: navy left panel + white form right |
| **Phone → Sheets/Graphs** | `AuthIllustration` control (spreadsheet grid, bar chart, trend line) |
| **Marks Management dashboard** | KPI row, Assessment Progress table, Quick Actions, AI Insights, Recent Activity |
| **Bright Future sidebar** | `NavigationView` with module links + school branding |
| **Students dashboard** | KPI card pattern, chart placeholders (next phase) |
| **Financials dashboard** | Status footer bar pattern (DB, backup, sync, health) |

**White workspace focus:** All data cards, tables, and lists live in the scrollable white content area — sidebar and footer are shell chrome.

| **Data Entrant** | Dashboard, Marks Entry, Assessments; Moderation hidden |
